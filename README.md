# NT101 — An toàn Mạng máy tính

Kho mã nguồn các bài Lab môn **An toàn Mạng máy tính (NT101)** — Trường Đại học
Công nghệ Thông tin (UIT), Khoa Mạng máy tính và Truyền thông.

**Ngôn ngữ sử dụng:** C++ (C++17)

## Cấu trúc kho mã nguồn

```
NT101/
├── README.md          # File này
└── Lab01/              # Mật mã học Cổ điển (Classical Cryptography)
    └── README.md       # Chi tiết từng task, cách build & chạy
```

Mỗi bài lab được lưu trong thư mục riêng, có `README.md` mô tả mục tiêu, nội
dung chính và hướng dẫn chạy chương trình.
